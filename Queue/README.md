# Queue

A FIFO (first-in, first-out) queue backed by a singly linked list with
head and tail pointers.

## Complexity

| Operation | Time | Notes |
|-----------|------|-------|
| `Enqueue` | O(1) | |
| `Dequeue` | O(1) | |
| `Peek`    | O(1) | |

- **Space:** O(n) for n elements.

## Run

```bash
dotnet run --project Queue
```

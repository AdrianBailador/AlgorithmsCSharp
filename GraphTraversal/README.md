# GraphTraversal

Breadth-First Search (BFS) and Depth-First Search (DFS) over an
undirected graph represented as an adjacency list.

## Complexity

- **Time:** O(V + E), where V is the number of vertices and E the
  number of edges — every vertex and edge is visited once.
- **Space:** O(V) — the visited set, plus the BFS queue or the DFS
  recursion stack.

## Run

```bash
dotnet run --project GraphTraversal
```
